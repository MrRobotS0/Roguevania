# Acervo de arte garimpada

Catálogo de arte gratuita que já foi **olhada**: o que o desenho mostra, a licença e para quem
serve no MOKSHA. Base para o grande update de conteúdo (mais inimigos, mapas, fases, skins).

**Regra:** só entra arte cujo desenho case com quem o personagem é na história. Antes de usar,
conferir:
- o que o desenho mostra;
- a licença;
- se a licença deixa a arte ficar num repositório **público**. Algumas proíbem "distribuir", e o
  GitHub do MOKSHA é público.

Legenda: ✅ em uso · 🟢 serve e está pronto para usar · 🟡 serve com ressalva · ⛔ não serve (motivo).
